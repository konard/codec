# My Codec - Полностью новый сериализатор/десериализатор для Go

**Это полностью новое решение, написанное с нуля без использования существующего пакета codec.**

## Описание

Сериализатор/десериализатор, способный конвертировать **ЛЮБОЕ** значение Go в бинарный формат и обратно.

## Особенности

✅ **Полностью собственная реализация** - не использует существующий пакет
✅ **Поддержка всех типов Go**:
- Примитивы: bool, int*, uint*, float*, complex*, string, uintptr
- Коллекции: массивы, слайсы, мапы
- Структуры с вложенностью
- Указатели с поддержкой цикличных ссылок
- Интерфейсы
- Каналы
- Функции

## Использование

```go
// Сериализация
data, err := Serialize(value)

// Десериализация  
result, err := Deserialize(data)
```

## Пример

```go
package main

func main() {
    // Примитивы
    data, _ := Serialize(42)
    result, _ := Deserialize(data)
    fmt.Println(result) // 42
    
    // Слайсы
    data, _ = Serialize([]int{1, 2, 3})
    result, _ = Deserialize(data)
    fmt.Println(result) // [1 2 3]
    
    // Мапы
    data, _ = Serialize(map[string]int{"a": 1, "b": 2})
    result, _ = Deserialize(data)
    fmt.Println(result) // map[a:1 b:2]
    
    // Цикличные структуры
    type Node struct {
        Value int
        Next  *Node
    }
    n1 := &Node{Value: 1}
    n2 := &Node{Value: 2}
    n1.Next = n2
    n2.Next = n1  // цикл
    
    data, _ = Serialize(n1)
    result, _ = Deserialize(data) // работает!
}
```

## Архитектура

### Бинарный протокол

```
[Type Registry Section] [Value Section]
```

**Type Registry:**
- Содержит метаданные обо всех типах, используемых в значении
- Типы упорядочены так, что элементные типы идут перед контейнерными

**Value Section:**
- Сериализованные данные с ссылками на типы из реестра
- Указатели отслеживаются для поддержки цикличных ссылок

### Ключевые компоненты

1. **TypeRegistry** - управление регистрацией типов с поддержкой цикличных типов
2. **Serializer** - обход графа значений и кодирование в бинарный формат
3. **Deserializer** - восстановление значений из бинарного формата

## Технические детали

- Использует `reflect` для анализа типов во время выполнения
- Отслеживание указателей через `uintptr` для обработки циклов
- Бинарное кодирование через `encoding/binary` (LittleEndian)
- Автоматическая регистрация типов в правильном порядке
